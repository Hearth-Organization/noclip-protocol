# HUD fonts
The approved HUD mockup's fonts, loaded by NoclipHudComponent:
- IBM Plex Mono Regular, Medium, SemiBold (SIL Open Font License, OFL-IBMPlexMono.txt), from github.com/google/fonts.
- Oswald Bold (SIL Open Font License, OFL-Oswald.txt): the weight-700 instance of Oswald[wght].ttf from github.com/google/fonts,
  made with fontTools (`instantiateVariableFont(font, {"wght": 700})`).
