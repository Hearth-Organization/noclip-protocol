# Level 0 textures
Generated by Tools/Level0/make_textures.py (numpy + Pillow); rerun it to remake or tweak them.
The filename suffix (_basecolor, _normal, _roughness, _emissive) picks O3DE's image preset.
- `level0_film_grain.png`: film grain noise for the level's Film Grain effect (Tools/Level0/make_film_grain.py). Used instead of the engine's FilmGrain.jpg, which doesn't process on Linux.
